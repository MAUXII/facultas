## Adding a print

1. Use a README the user pointed to, or one you are allowed to browse.
2. Capture the first screen of the README only (not the whole repository page), in the theme that shows the design best.
3. Name it `<composition>-<project>.png`.
4. Add a row here with the source link, date, and what it teaches.
5. Mention it in the matching reference file.
