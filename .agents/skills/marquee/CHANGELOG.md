# Changelog

## 1.0.0 — 2026-10-29

First release.

- Workflow in seven steps: inspect, read identity, direct, plan assets, write, validate, hand off.
- Five modes: create, redesign, directed, refine, review.
- Eight compositions, with full guides for Centered Identity and Banner-First.
- `scripts/inspect_repository.py`: manifests, commands, license, CI, docs, images, colors, fonts; env names only.
- `scripts/validate_readme.py`: links, images, alt text, anchors, unsupported HTML, badge count, centered body, hype words, long code lines; `--json`, `--strict`, `--check-urls`, `--assume-exists`.
- Four worked examples (tessera, loomwork, logfmt, driftboard) with original SVG assets.
- Reference print of a banner-first README (api-anything).
- Eight judgment scenarios in `evals/` and 17 script tests in `tests/`.
